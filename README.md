# Tugas Slicing Website - Pemrograman Website

Website hasil slicing untuk tugas mata kuliah Pemrograman Website. Dibangun menggunakan HTML, CSS (Plain CSS, tanpa framework), dan JavaScript (DOM Manipulation).

## 📝 Deskripsi

Website ini merupakan landing page sederhana yang terdiri dari:
- **Header/Navbar** — navigasi responsif dengan hamburger menu di tampilan mobile
- **Hero Section** — bagian sambutan utama dengan gambar dan tombol interaktif
- **Artikel Section** — konten artikel
- **Tentang Section** — informasi tentang website/pemilik
- **Footer** — informasi tambahan dengan tahun otomatis

## ✨ Fitur JavaScript (DOM Manipulation)

1. **Ubah teks sambutan** — tombol "KLIK DISINI" mengubah teks judul hero secara dinamis
2. **Toggle menu mobile** — hamburger menu membuka/menutup navigasi di layar kecil, dan otomatis tertutup saat salah satu link diklik
3. **Tahun otomatis di footer** — tahun copyright di footer ter-generate otomatis menggunakan `Date()`

## 📱 Responsive Design

Website telah diuji dan responsif pada tiga breakpoint:
- **Mobile** (< 768px) — menu navigasi menggunakan hamburger button
- **Tablet** (768px - 1024px)
- **Desktop** (> 1024px)
